Single-line text field on a sunken surface with a calm focus ring. The city search uses it with `icon="search"` and `loading` while geocoding.

```jsx
<Input icon="search" placeholder="Знайдіть місто" size="lg" loading={isSearching} />
```

Props: `icon`, `size` (`md`/`lg`), `loading`, `disabled`. Forwards standard input attributes.
