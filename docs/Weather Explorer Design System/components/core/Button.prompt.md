The brand's primary action control — calm sky-blue fill, soft rounding, a gentle press (scales to 0.99). Use for any commit action; pair with an icon for clarity.

```jsx
<Button variant="primary" iconLeft="locate-fixed">Моє місцеположення</Button>
<Button variant="secondary">Порівняти вихідні</Button>
<Button variant="ghost" size="sm" iconRight="chevron-right">Деталі</Button>
```

Variants: `primary` (sky fill), `secondary` (sky tint), `outline`, `ghost`. Sizes: `sm` / `md` / `lg`. Props: `iconLeft`, `iconRight` (Lucide names), `fullWidth`, `disabled`.
