Small status pill. `tone` maps to a semantic colour (good/fair/poor share the comfort palette).

```jsx
<Badge tone="brand">Вихідні</Badge>
<Badge tone="good" solid>Чудово</Badge>
```

Tones: `neutral`, `brand`, `accent`, `good`, `fair`, `poor`. `solid` for filled, otherwise soft tint. Sizes `sm`/`md`.
