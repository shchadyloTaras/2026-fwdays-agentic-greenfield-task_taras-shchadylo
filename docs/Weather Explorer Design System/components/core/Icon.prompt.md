Renders a single Lucide line icon at the brand's calm 1.75 stroke; use for every glyph in the UI. Requires the Lucide UMD script loaded globally.

```jsx
<Icon name="cloud-rain" size={22} />
<Icon name="search" label="Пошук міста" />
```

Decorative by default (aria-hidden). Pass `label` to expose an accessible name. Colour follows `currentColor`, so set it on the parent.
