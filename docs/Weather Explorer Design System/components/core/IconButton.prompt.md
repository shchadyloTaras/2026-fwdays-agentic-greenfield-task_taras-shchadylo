Square icon-only control for map zoom, theme toggle, pin/unpin, close. Always pass an accessible `label`.

```jsx
<IconButton icon="plus" label="Збільшити" variant="outline" />
<IconButton icon="x" label="Закрити" variant="ghost" />
```

Variants: `solid` / `soft` / `outline` / `ghost`. Sizes: `sm` (32) / `md` (40) / `lg` (48). Presses to 0.94 scale.
